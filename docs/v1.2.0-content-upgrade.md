# v1.2.0 内容与照片升级

本版范围来自 `website-audit-2026-10-14.md` 及用户逐项确认。报告中 R01–R05 是作者复现的问题，C01–C04 是待验证候选，I01–I05 是功能建议；不能把全部条目都当作线上漏洞。

## 已确认的产品行为

- 随笔与项目新建时默认自动日期，在首次发布时填入北京时间日历日；可手工指定。随后更新不改变自动首次日期。系统创建时间与真实发布时间单独保留。
- 照片故事默认使用拍摄日期；新故事日期空且照片日期一致时可自动带入，多日期列为候选。未知可留空，读者页隐藏日期；追加照片不覆盖人工日期。
- 旧记录保留已有日期，列表与详情统一；不猜测缺失的历史首次发布时间，不批量改写地点或日期。
- 栏目、文章与问卷有独立浏览器标题；公开页面在初始 HTML 中提供摘要、封面、Open Graph 和 canonical。私密回复、草稿、未公开内容不提供私人分享信息。
- 导航表达当前栏目，提供跳到正文入口和可见键盘焦点。交互地图保留逐个可聚焦标记及独立故事列表。
- 问卷进度统计当前有效必答项：矩阵每行一项，条件隐藏及提前结束后的题不计，选填不计。通过该项验证才计入，全部选填直接提示可提交。填写达标仍是待提交，只有成功响应才表示保存成功。

## 照片工作台与位置

一次选图属于当前故事，不自动拆成多篇。上传前显示本机缩略图、拍摄日与 GPS 候选；支持逐张进度、取消、重试、移除、排序、替代文字、图注和封面。已插入正文的图不在页尾重复排列。

GPS 由作者选择后才应用，且必须来自成功上传的图片。失败不替换原地点。查地名由主动操作触发，界面说明 Nominatim（OpenStreetMap）接收坐标或搜索词；读取 EXIF、选图和取消候选均不自动查询。作者始终可以手填。

| 公开精度 | 访客得到的信息 |
| --- | --- |
| 精确 | 明确确认的精确坐标与公开地名 |
| 城市或地区 | 单独确认的区域代表点与公开地名，不含原 GPS 或详细地址 |
| 不显示地图 | 不含坐标；可保留作者明确填写的公开地名，故事仍可从列表阅读 |

新故事默认城市或地区。旧记录没有精度字段时兼容原有精确公开设置。原始 GPS 和详细地点仅用于后台；公共投影、文章接口、摘要、分享和媒体引用检查均使用公开信息。图片继续经过既有元数据清理流程。备份中的原件不因本版自动删除。

站内相册支持同篇故事的图片切换、缩略图、图注、键盘左右与 Escape、焦点恢复和手机操作；大图按需加载。它不是跨故事的图库或社交相册。

## 项目 PDF 与助手入口

项目可保存多个 PDF 附件及其名称、顺序、大小、可选版本和日期，提供预览／下载。沿用现有 15 MiB 单文件上传限制与草稿／正式发布分离；附件只有被正式公开内容引用时才匿名可读，下架后仍按当前有效的其他公开引用判断共享文件访问。

实际报告文件由用户另行指定；升级不自动寻找或公开“金镜实验报告”。PDF 保留原字节，图片 EXIF 清理不等于 PDF 内容或作者信息清理。

Friday／Codex 沿用本机管理脚本，同步支持日期、照片资料、定位精度和附件。默认保存草稿，发布仍需用户明确内容及目标、核对本机预览；版本冲突、幂等、批量事务和失败回滚规则不变。此入口仍依赖本机在线，不隔离 Workbench 原有运维权限。

私人草稿收件箱、视频、后台 AI 侧栏与朋友圈导入不在范围。
