```powershell
npm test
python -B -m unittest discover -s atlas -p "test_*.py" -q
node --test atlas/tools/test-comet-orbit.mjs
npm run build
```

2026-10-13 的发布前结果：Node 99／99、Python 60／60、彗星轨道 20／20 通过，生产构建通过。真实浏览器确认资料并发冲突保留本地修改并可载入新版、问卷未保存离开提示。DEPLOY01 另用真实 Linux 的独立 oneshot unit 验证目录初始化，未把隔离 unit 的成功写成生产服务已切换。

后端测试使用临时数据库，媒体使用合成 GPS 和色块图片，天气使用合成网格，通知使用模拟提供商；前端交互回归使用可控 DOM 和延迟／失败响应。自动化断言不代表真实设备的全部视觉与交互验收。

私密图片访问控制不能撤回他人已下载的副本。旧图元数据仍可能存在于私有原件和备份中，PDF 不纳入图片清洗。已进入第三方发送流程的通知无法撤回，交付状态不确定时需要人工核实后重试。

本版没有通过这些测试宣称解决 ICP 备案、完成真实摄像头动作测试或验证真实通知送达。生产 Nginx、systemd、域名 HTTPS、数据保留和发布版本一致性须单独验收，记录见 [部署文档](../deploy/README.md)。

2026-10-13 已完成正式服务切换：Nginx 配置检查、systemd 运行、HTTPS 关键路径、匿名权限和现有公开媒体通过；数据库内容／设置与上传原件校验一致。Linux 另验证图片专项 10 项与网关 1 项，均通过。构建超时与正常重启恢复经过已写入部署记录。
