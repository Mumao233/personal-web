# v1.3.1 问卷更新

版本号按用户 2026-10-15 的明确要求使用 v1.3.1；基线为已部署 v1.3.0（c480ad3）。完整设计与验证计划见 [设计](superpowers/specs/2026-10-15-survey-v131-design.md) 和 [实施计划](superpowers/plans/2026-10-15-survey-v131.md)。

## 使用方法

后台问卷列表提供“复制普通链接”和“复制独立填写链接”。普通地址沿用 `/?page=you&survey=<id>`，独立地址附加 `&standalone=1`。两者对应同一份问卷及统计。

独立页面初次显示不挂载主站导航、菜单、主页入口或无关模块。仅成功保存答卷的服务器响应能恢复导航，成功提示留在原页。错误、未开放、关闭、过期或不存在时保持独立；刷新及重新打开再次进入独立状态。超时重试使用同一提交回执，不能凭本机完成标记显示导航。独立模式不改变公共主页访问权限。

编辑器中可正常回车和粘贴多行文本。预览、保存和服务端忽略空白选项行，保留其他选项文字与顺序。重复、只有首尾空格不同的冲突、数量不足/过多和超长分别报告；不会自动合并或修剪。错误列表可定位题目及字段，失败后原始内容保留。

历史答案以选项原文匹配；已有答案使用的选项、矩阵行、题型和题目不能被无映射地删除或改名。请保留对应项，或者新建问卷。规则失效会明确报错，不静默删除跳题、互斥或提前结束条件。此版本不批量修改或发布生产问卷。

## 发布与回滚要求

前端本地构建并生成哈希清单；生产复用未变化的 Linux 依赖及 Atlas 数据，不在服务器构建。部署前在 `/opt/personal-web/backups/v1.3.1` 备份一致性数据库、上传文件和旧应用，候选应用位于 `/opt/personal-web/releases/v1.3.1`。切换前再次备份数据，以涵盖准备期间的新增填写。

回滚时恢复旧应用并继续使用当前 `/opt/personal-web/data`，不恢复旧数据库覆盖新内容。正式部署提交由服务器 `release.json` 记录，并须与远端 main、附注标签 v1.3.1 及同名 GitHub Release 一致。
