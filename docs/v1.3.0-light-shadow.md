## 实现

- 近黑深色为默认，暖白浅色覆盖公开页面、文章、问卷、地图、管理登录、编辑器、统计、媒体与恢复状态；保留铜色和原内容。
- 页面首绘前读取明确的浏览器主题选择。存储受限时保持可切换，不监听系统深浅变化。后台与公开页使用同一选择，跨标签页同步。
- 主题颜色令牌插值为 250ms；照片、上传媒体和画布没有反色滤镜。独立 `atlas/solar` 无文件差异。
- 桌面按钮在导航右端；手机按钮在菜单顶部；管理登录页和管理侧栏也可切换。
- 手机导航挂载到页面根部的固定层，宽 80vw，300ms ease-out 进退。链接轻微顺序淡入，关闭时反向淡出。局部轻磨砂背景从左透到右实，文本不应用模糊。
- 页面不锁滚动，不添加横向位移。左侧暴露区保留纵向手势，区分轻点与滑动；菜单自己滚动，overscroll contain 阻断滚动串联。导航、Escape 与关闭按钮收起菜单，键盘焦点恢复不滚动页面。
- Reduced Motion 使用 80ms 淡变，关闭位移和错峰。没有新增页面、卡片或滚动动画。已有桌面导航没有下拉菜单；为已有/未来导航下拉状态保留 180ms 下移淡入样式，不新增下拉结构。

## 预览与正式源码的隔离

独立静态预览只带真实前端和浏览器内存模拟数据。任何保存/发布或问卷操作都只影响当前页面的临时数据，重新加载重置。上传、账号修改、真实通知、地名外查及文件导出关闭。太阳系依赖 Python，未部署到静态预览；入口明确解释，不跳转或代理生产。

## 验收边界

用户已经查看最新私有预览并批准发布。云浏览器在 ChatGPT 登录边界停下，未请求登录或改变预览访问范围，因此没有把云浏览器视觉、实际触摸滚动、各断点及 Reduced Motion 的完整设备矩阵记为通过。自动化 DOM 检查不能替代这些真实设备结果；正式上线后进行只读页面与主题状态检查，并保留用户反馈入口。

## 2026-10-15 测试反馈修正

根据手机截图中“渐变太突兀”的反馈，将原本直接施加在菜单容器上的 10px 背景模糊移到独立固定底层。底层采用 6px 轻磨砂与均匀暖白/深色主体，并用约 80px 多段蒙版同时羽化底色和模糊，避免左侧透明区出现突然的模糊竖边和大标题暗影。文字及滚动层不做模糊或蒙版；80% 面板、触摸、滚动和动画参数不变。

该修正先只更新隔离开发副本及同一个私有预览，新增两项视觉层结构与可访问性回退检查。用户随后明确批准此版上线；发布范围不追加其他视觉或数据变更。

## 正式发布要求

- 版本固定为 1.3.0。依赖版本、真实后端、数据结构和 Atlas 目录不变，不初始化或迁移生产数据库。
- 前端在已验证的构建环境完成，不在既有小内存服务器运行 Vite 构建；部署包不含 node_modules、私人数据、上传文件、缓存、凭据或演示适配器。
- 覆盖式应用包不含完全未变的 Atlas。先将旧应用完整复制到独立候选目录，再覆盖包内文件，保留 atlas/ 和 atlas/.runtime/；不能把覆盖包解压到空目录后直接启动。
- 切换前备份服务器 SQLite 一致性副本、上传文件及旧应用。继续使用 /opt/personal-web/data，不从本地传数据库或测试数据。
- 保留既有 Nginx、systemd、TLS、通知和环境变量设置，不为本次主题更新变更安全配置。
- 候选应用中 release.json 必须记录 1.3.0 与准确发布提交。切换后核验服务、HTTPS首页、太阳系、健康/状态接口、匿名后台拒绝与敏感路径保护，以及主题/菜单的受影响页面。
- 回滚仅恢复旧应用；没有明确数据恢复要求时，不恢复旧数据库或上传文件覆盖用户新增内容。
- 生产验收成功后，才为同一准确提交创建附注标签 v1.3.0 和同名 GitHub Release，并核验远端 main、标签、Release 与服务器发布清单一致。
