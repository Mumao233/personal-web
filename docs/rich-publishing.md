# 图文发布

在 `/?page=admin` 登录，进入「作品与项目」「随笔」或「关于世界」，选择新建或编辑。

## 写作与插图

- 在正文里直接输入文字。工具栏支持二级／三级标题、加粗、斜体、列表、引用、链接、撤销和重做。
- 将光标放在需要的位置，点击「＋ 图片」选择文件，也可以拖入图片或粘贴截图。支持 JPG、PNG、WebP、GIF，每张不超过 15 MB。
- 点击正文图片，可填写说明和替代文字，调整宽度，选择独占一行、靠左环绕或靠右环绕；上移／下移按钮调整顺序。
- 手机窄屏自动将图片和文字上下排列。编辑页「预览文章」提供电脑／手机预览。
- 封面独立用于作品和随笔的列表入口。照片故事保留地点、地图与相册，并可从相册插入正文；正文或封面已显示的图片不会在文末相册重复出现。
- 删除正文图片不会删除上传文件，也不会删除相册里的原图。

服务器会重新编码上传图片，清除 EXIF／IPTC／XMP 等元数据（包括 GPS），按原方向显示并转换到 sRGB；GIF、WebP 保留动画帧、延时与循环信息。新图片首次读取直接复用净化结果。头像、封面、相册和正文图片走同一上传与读取机制。

仅用于草稿、已经撤下且无其他公开引用、或尚未使用的媒体需要管理员登录。发布后的图片、附件可以匿名读取；同一文件仍被另一篇公开文章或公开资料引用时，撤下一篇文章不会使它失效。每次请求都会重新核对公开引用，不依赖随机文件名保密。请注意，已经由访客下载或截图的内容无法远程收回。

旧上传图片仍保留在服务器私有数据目录，网页只提供清洗后的缓存副本，不会直接返回带元数据的旧图。PDF 沿用原文件字节，不属于图片元数据清洗范围；公开前应自行检查其内容。本站绝对 URL 由服务器可信来源配置识别，外部网站的同名路径不会使本地文件变为公开。

## 草稿与发布

停止输入约 1.2 秒后自动保存草稿，也可点击「保存草稿」。未命名或未确认地点的内容可以先存为草稿。

点击「发布文章」才会公开。修改已发布文章时，线上保留旧版本；点击「更新发布」才替换。独立阅读链接分别为 `/?project=ID`、`/?post=ID` 和 `/?story=ID`。

上传未完成或上传失败尚未处理时，发布按钮不可用；重试或移除失败任务后继续。发布前会保存最新草稿。故事仍需要确认公开的精确位置。

返回列表、切换后台栏目或退出时会先保存；保存失败会保留编辑器并显示错误。刷新／关闭页面前有未保存的修改会触发浏览器提示。断网期间请勿强行关闭窗口。

多个窗口编辑同一篇文章时，服务器拒绝旧版本覆盖新版本。冲突出现后暂停自动重试并保留本地修改；可使用「复制本地修改」备份完整编辑数据，再选择「放弃本地修改并载入最新版」或返回列表。若剪贴板不可用，界面提供可选中复制的备份文本。重新载入会同时更新表单与富文本正文，无需陷入旧版本反复保存。

退出后台会清除原编辑器状态，重新登录后从服务器最新内容打开。地图视图、缩放等控件只改变地图，不会触发外层发布表单。地点搜索以当前查询为准，较早发出的慢响应不会覆盖新结果。

「撤下文章」取消公开并保留内容。旧纯文字内容无需迁移，打开后继续编辑即可。

## 验证边界

自动化测试覆盖三个内容类型的草稿隔离、发布和撤下、版本冲突及恢复、旧数据兼容、正文结构和链接校验、独立阅读与图片去重。媒体回归使用合成 GPS JPEG、双帧 GIF／WebP 和临时 PDF，检查位置元数据、方向、色彩、动画、读取权限及失败上传清理；通知测试使用模拟提供商。

v1.0.1 的真实浏览器检查确认：两个资料窗口的过期保存出现冲突并保留本地修改，可以载入新版；问卷未保存修改离开时显示选择弹窗。这些检查使用隔离环境，不向生产内容库写测试记录。

v1.0.0 的隔离浏览器验收包括：粘贴图片上传、图注／替代文字、图片移动与左侧环绕、草稿恢复、首次发布、修改后公开版本不变、更新发布，以及 390px 手机布局。上传接口也用 JPG 文件验证。Chrome 自动化扩展未启用本地文件访问，因此该扩展的文件选择器自动上传路径未能验收；拖入路径与粘贴／选择共用上传队列，未模拟系统拖放。v1.0.1 新增回归位置见 [报告逐项对照](v1.0.1-review-fixes.md)。

编辑器基于 MIT 许可的 Tiptap / ProseMirror；富文本以受限 JSON 文档保存，服务端不接受任意 HTML。访客接口不会返回草稿或管理版本信息。数据库和上传文件应通过服务器备份流程保护，不纳入 Git。
