# 九格图片工具集成

九格是个人网站内的功能页面，地址为 `/nine-grid/`，通过「作品与项目」中的作品卡片进入。入口没有加入首页、主导航或主题区域；网站原有栏目与内容保持原样。

## 体验

多选上传或拖入照片后，自动排入画布，超过九张时新增画布。照片可以拖动换位，切换裁切模式后可以平移，滑杆控制等比例缩放。空白格、格子间距和四周留白都会保留在最终 PNG 中。支持撤销、重做，多个画布可一次打包为 ZIP。

导出默认 3000×3000，也可选择 1080、2048、4096。始终使用原图绘制到不透明白色 Canvas；主站深浅主题只影响编辑器外壳。图片不提交给后端，当前编辑只存在本次浏览器页面中，刷新或离开前需导出。

## 工程

- 源码：`apps/nine-grid`，React + TypeScript + Vite + Canvas。
- 主题：导入主站 `src/theme-tokens.css` 与主题状态模块，读取 `personal-space-theme`，不另增主题按钮。
- 构建：先在子项目构建到生成目录 `public/nine-grid`，再由主站 Vite 复制到最终 `dist/nine-grid`。根项目运行时依赖不变，生产服务器不构建前端。
- 服务：`server/index.js` 明确返回九格 HTML，避免落入主站单页回退。资源统一使用 `/nine-grid/` 前缀，避开 Atlas 的 `/assets/` 路由。
- 入口：`src/main.jsx` 的作品列表与 `src/nine-grid-project.css`。采用与既有太阳系相同的代码内置作品入口，不修改生产数据库。

首次本地构建需依次执行 `npm ci`、`npm ci --prefix apps/nine-grid`、`npm run build`。Windows 启动脚本也会在需要构建九格时安装其缺失依赖。

## 验证与发布边界

核心逻辑测试：`npm --prefix apps/nine-grid test`。主站回归：`npm test`。真实浏览器测试使用隔离本地数据库与合成图片，覆盖站内入口、主题继承、拖拽裁切、撤销、实际 PNG 和 ZIP 导出以及窄屏布局。

生产只做读取验证，不导入测试作品、问卷或答卷。发布前备份数据库、上传文件与旧应用；代码回滚不覆盖现有数据库。实际检查结果记录在本次服务器 `release.json` 和 GitHub Release。

2026-10-27 本地验证：主站 316 项回归与九格 14 项核心测试通过，TypeScript 检查及两阶段生产构建通过。Chrome 的 12 项真实站内验收通过，含四档实际 PNG 像素、ZIP 解包、裁切与撤销、作品入口、深浅主题继承、跨标签页主题同步和 390px 布局。验收期间照片仅使用合成数据，没有向生产写入内容；实体手机与其他浏览器未在本次测试范围内。
