# 可以后续补充的素材

现有素材足够完成整合、3D 首页和手势控制，以下内容不阻塞开发。

1. **个人照片（可选）**：喜欢的一张头像或半身照，建议原图；不提供也可保留纯文字与宇宙场景。
2. **旅行照片与地点**：用于线条地球，保留 EXIF 原图最佳；否则给出城市或具体地点。通过后台上传即可。
3. **作品材料**：每件作品的标题、你具体做了什么、1–3 张截图、可公开的链接。没有证据的成果不编造。
4. **公开联系方式**：希望展示的邮箱、微信或 GitHub；只发布你主动提供并指定公开的内容。
5. **随笔**：可直接从后台添加，不需要预先提供。

## 上线阶段

已有域名的域名名称，以及最终选用的服务器或托管平台。这次提供本地整合项目，不修改域名或发布账户。
对外摄像头功能需要 HTTPS（本机 localhost 可以使用）；无需购买动作捕捉硬件，普通摄像头即可。
邮件/短信通知仍需要用户自己的服务配置，未配置时不声称通知已发出。

## 手势验收

开发使用模拟关键点和摄像头生命周期测试，不擅自开启真实摄像头。
交付后需要在你的设备上主动开启一次，验证光照、摄像头角度、双手空间与跟踪效果。
