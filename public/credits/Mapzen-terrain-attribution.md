# 地形数据来源与署名

本网站的地形高度来自 Mapzen Terrain Tiles（Terrarium 编码），由 Tilezen / Joerd 项目汇集与处理。它是地形模型，不代表现场实时测量。

- Mapzen Terrain Tiles / Tilezen Joerd：https://github.com/tilezen/joerd
- 数据提供方、适用区域与各数据集许可的完整原始清单：https://github.com/tilezen/joerd/blob/master/docs/attribution.md
- Mapzen 地形服务说明：https://www.mapzen.com/documentation/terrain-tiles/

地形图层的常见来源包括 USGS、SRTM、GMTED2010 与 ETOPO1。具体瓦片可能组合不同机构的数据；请以原始清单中的数据来源和相应许可为准，不将所有数据概括为同一种许可。
